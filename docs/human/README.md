# Human docs

Plain-language, narrative explainers written for people to read top to bottom —
the story and the *why*, with diagrams. Each doc here is self-contained: read it
on its own, no jumping between files. When a concept is easier to grasp as a
walkthrough than as a terse decision record or an API reference, it belongs here.

## Contents

- `how-swebench-runs.md` — end-to-end walkthrough of a full SWE-bench run:
  prepare → generate → score, why each instance needs its own container, how the
  agent runs inside it, and how a whole dataset is run and scored.
