# Decisions

This directory contains architecture decision records.

Create a decision record when the project commits to a meaningful technical or
product direction, especially if future contributors may wonder why it was chosen.

## Conventions

- Copy [template.md](template.md) for a new record.
- Name the file `YYYYMMDD-slug.md` — today's date plus a short kebab-case slug.
  The **slug is the ADR's stable id**: reference other ADRs by slug (e.g.
  `tool-result-as-content-block`), never by a sequential number. Date prefixes
  avoid the merge conflicts a global counter caused.
- Fill the front-matter (`title`, `status`, `date`, `slug`, optional `note`).
- Run `python docs/decisions/build_index.py` to regenerate the index below; the
  index is generated, so never hand-edit it (that was the other conflict source).
