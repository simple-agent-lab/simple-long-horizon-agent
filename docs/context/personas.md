# Personas

## Student Learner

Wants to understand how an agent loop works, how tools are called, and how state changes over time.

Needs:

- Clear concepts.
- Small examples.
- Minimal setup.
- Code that can be changed without reading a large framework.

## Team Explorer

Works inside a company team and wants to test whether agents can help with internal tasks.

Needs:

- A small base that can be adapted to local workflows.
- Explicit architecture choices.
- Simple extension points.
- Enough structure for team collaboration.

## Agent Contributor

Uses an AI coding agent to extend the project.

Needs:

- A stable collaboration contract.
- Clear task specs.
- Decision records.
- Context files that explain intent, not only file locations.
